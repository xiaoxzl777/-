# 前端设计规范

> 风格：清新文旅风（已确认）
> 效果预览：`docs/design/清新文旅风-精修版.html`，用浏览器直接打开。预览页里的内容是杭州，只用来看风格；正式数据是广州。预览页的“AI 规划”页面是改成对话式之前的布局，页面结构以本文第 8 节为准。

## 1. 技术选型

- React + TypeScript + Vite
- 组件库 Ant Design，用主题配置统一颜色和圆角
- 路由 React Router，请求 axios
- 图标 Phosphor Icons（`@phosphor-icons/react`）
- 地图：第一版用示意地图（按坐标画出各站、连线和珠江作参照）；以后申请到高德 Key 再换成高德 JS API

## 2. 颜色

全站只有一个强调色（湖水青），成功状态也用这个颜色。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面背景 | #F3F6F5 | #0C1412 |
| 卡片与面板 | #FBFCFC | #121C1A |
| 次级底色 | #EDF2F0 | #182421 |
| 分割线与描边 | #D9E2DF | #25342F |
| 正文 | #14201D | #E4ECE9 |
| 次要文字 | #45534F | #B1BFBA |
| 辅助文字 | #5E6D69 | #92A19C |
| 主色 | #0B7F6B | #3FC2A5 |
| 主色浅底 | #E0F0EB | #15302A |

插画另有一套绿色系配色，外加一个只在插画里使用的暖色点缀（#EE9A73），具体数值见预览页源码里的 `--il-*` 变量。

## 3. 字体与字号

- 字体：`"HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`
- 时间、价格等数字用等宽数字（`font-variant-numeric: tabular-nums`）

| 用途 | 字号 / 字重 |
|---|---|
| 首页大标题 | 54 / 700 |
| 区块标题 | 30 / 700 |
| 卡片标题 | 17 / 600 |
| 正文 | 15，行高 1.75 |
| 辅助文字 | 13 |

## 4. 圆角、阴影、间距

- 卡片、面板、插画：16px 圆角
- 卡片里的缩略图：10px
- 按钮、输入框、标签、筛选：全圆角
- 阴影只给会浮起来的层：悬停的卡片、地图控件
- 间距以 4 为基数，常用 8、12、16、24、32、48

## 6. 小萧形象

- 小萧是傲娇的小男生，头像和景点插画同一画风（扁平、主色系），圆形头像
- 4 种表情：

| 表情 | 代码 | 什么时候用 |
|---|---|---|
| 得意 | `PROUD` | 主动问候、普通闲聊、行程排好没有问题 |
| 不耐烦 | `ANNOYED` | 无关请求、其他城市、让他忽略规则 |
| 关心 | `CARING` | 有提醒：闭馆、超预算、暂不支持的需求、实时信息 |
| 思考 | `THINKING` | 等待回复时（前端自己切换） |

- 出现位置：
  - 首页输入框左侧，小尺寸，提示语是“跟小萧说说你的出行想法”；
  - 小萧页面：每条小萧消息左边是头像，表情跟着这条回复变化；
  - 等待回复时，先显示一个“思考”表情的气泡，里面是跳动的省略号，回复到了再替换成正式内容。
- 切换表情时淡入淡出，悬停时头像轻轻晃一下

## 7. 动效

- 悬停反馈 160ms，状态切换 240ms，进场 520ms；缓动曲线 `cubic-bezier(.16, 1, .3, 1)`
- 只改变透明度和位移
- 悬停在插画上时画面会动（太阳、飞鸟、船、摆动的树等），移开就停
- 首屏插画随鼠标产生视差；导航下划线跟随鼠标；主按钮箭头前移并扫光
- 小萧页面：消息气泡从下方淡入；规划回复下方的执行步骤逐条出现；时间线和地图标记联动高亮，地图标记悬停时显示站名和时间
- 系统开启“减少动态效果”时，以上动效全部关闭

## 8. 页面

| 页面 | 路由 | 布局要点 |
|---|---|---|
| 登录 / 注册 | `/login` | 游客用；居中表单卡片，登录和注册切换 |
| 首页 | `/` | 左边是标题、一句话输入框和示例需求；右边是插画；下面是热门景点和使用说明 |
| 景点列表 | `/pois` | 顶部是片区和类型筛选、搜索；下面是卡片网格 |
| 景点详情 | `/pois/:id` | 大插画、名称和标签、简介、开放时间表、闭馆日、门票价、官网链接 |
| 问小萧 | `/chat` | 顶部是标题、“新行程”和“保存行程”按钮。左栏是对话：小萧的消息靠左（头像 + 气泡，规划回复下面可以展开执行步骤），用户的消息靠右，底部是输入框；还没有行程时，输入框上方显示几条示例需求。右边是行程：最上面是条件标签（可修改），下面左边是时间线（每站可删除），右边是地图；还没有行程时显示空状态插画 |
| 我的行程 | `/trips`、`/trips/:id` | 列表是卡片；详情复用时间线和地图，并显示需求原话 |
| 后台登录 | `/admin/login` | 管理员用；居中表单卡片，只有账号和密码 |
| 后台：片区管理 | `/admin/districts` | 表格加弹窗表单 |
| 后台：景点管理 | `/admin/pois`、`/admin/pois/:id` | 表格（筛选、上下线）；编辑页分成基本信息、开放时间、闭馆日三块 |

- 游客端顶部导航：首页、景点、问小萧、我的行程，右边是登录状态和深浅色切换
- 后台用单独的布局：左侧菜单（片区管理、景点管理），右上角退出；大模型用不了时，内容区顶部显示一条红色提醒（比如“DeepSeek 余额不足，请充值”）
- 后台页面直接用 Ant Design 的标准表格和表单，颜色和圆角跟随主题
- 手机上各栏改为上下排列；问小萧页面分成“对话”和“行程”两个标签，排出行程后“行程”标签上出现提示点

## 9. Ant Design 主题配置

```js
import { theme } from 'antd';

export const lightTheme = {
  token: {
    colorPrimary: '#0B7F6B',
    colorBgLayout: '#F3F6F5',
    colorBgContainer: '#FBFCFC',
    colorBorder: '#D9E2DF',
    colorText: '#14201D',
    colorTextSecondary: '#45534F',
    borderRadius: 10,
    borderRadiusLG: 16,
    fontSize: 15,
    fontFamily: '"HarmonyOS Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif',
  },
  components: {
    Button: { borderRadius: 999, borderRadiusLG: 999, borderRadiusSM: 999 },
    Tag: { borderRadiusSM: 999 },
  },
};

export const darkTheme = {
  algorithm: theme.darkAlgorithm,
  token: { ...lightTheme.token, colorPrimary: '#3FC2A5', colorBgLayout: '#0C1412', colorBgContainer: '#121C1A',
    colorBorder: '#25342F', colorText: '#E4ECE9', colorTextSecondary: '#B1BFBA' },
  components: lightTheme.components,
};
```
