# 城市文旅行程规划平台（毕业设计）

面向广州自由行游客的行程规划网站。用户用一句话把出行想法告诉 AI 助手“小萧”，小萧结合景点开放时间、路程和预算，排出一份当天走得通的行程。

## 技术栈

- 后端：Spring Boot + MyBatis + MySQL
- 前端：React + TypeScript + Ant Design
- AI 规划模块：Python FastAPI + DeepSeek（没配 Key 时用规则解析）
